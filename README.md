# Ski Route Planner

A Java command-line application for planning ski routes based on available time, skiing ability, personal preferences, and route objectives.

Developed independently as a university programming project at the Karlsruhe Institute of Technology (KIT).

## Features

- Models a ski area as a directed graph of lifts and slopes.
- Loads and validates ski-area definitions from text files using a specified Mermaid-style format.
- Plans routes while considering lift opening hours, waiting times, and travel times.
- Accounts for skiing ability, slope difficulty, and surface conditions.
- Supports route objectives such as maximising distance, elevation descent, total slope runs, or the number of distinct slopes.
- Processes commands through an interactive command-line interface and reports invalid input.

## Technologies and Concepts

- Java
- Graph modelling and route optimisation
- File parsing and input validation
- Command-line interaction
